Entry for the make.fun bounty
["Sum up 21 November's world news in one image"](https://make.fun/bounty/news-image-20261121).

A professional newspaper front page summing up Saturday 21 November 2026:
the double-tap missile strike on Kryvyi Rih, COP31 talks in overtime, the
chip-stock rout, Mexico's capture of cartel boss "El Chapo Isidro", the
UK–EU post-Brexit reset, and the World Court's Rohingya genocide ruling.

- `main.py` — the entry program (Python 3.13, standard library only). It
  copies the shipped `entry.png` to `MAKEFUN_OUTPUT_DIR` or `/output`.
- `draw.py` — the Pillow renderer that draws the front page (original
  artwork, deterministic fixed seed). Run it offline to regenerate
  `entry.png`.
- `entry.png` — the rendered front page (1024×1024).
